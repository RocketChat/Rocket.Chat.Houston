    People
    
    
    Everyone here can sign in to this server. Roles bound the
      GUI only — anyone with a shell on this server is already in the docker
      group, so a readonly user with an ssh key is not readonly.
    
    
    
    
    
      
      
      
    
    
    
    houston generates the password and shows it once — an admin
      who types a colleague's password also knows it, which makes every audit line
      signed with that name deniable.
    
    
      

  
  
  
    
    Change your houston password
    
    
    Every other session you are signed in on ends. This one stays,
      so you are not signed out of the tab you changed it in.

        nobody — including an admin — can read it back.
